2. RUN THE FULL UPDATED SOURCE
Install Node.js 22+ (24 recommended). Open a terminal inside source/:
  npm ci
  npm run demo:showcase

3. PUSH THE THREE COMMITS FROM ANOTHER LAPTOP (RECOMMENDED)
Install Git and GitHub CLI. Log in as an account with write access:
  gh auth login --hostname github.com --git-protocol https --web --scopes repo
  gh auth setup-git

Clone the real repo into a NEW directory, outside this ZIP's source/ folder:
  git clone https://github.com/namansh70747/sentinel.git sentinel-publish
  cd sentinel-publish

Replace /FULL/PATH below with the extracted ZIP's absolute folder path.
Keep the quotes if the path has spaces. Forward slashes also work in Windows Git Bash.
  git fetch "/FULL/PATH/sentinel-handoff/transfer/sentinel-changes.bundle" demo/credential-free-showcase:demo/credential-free-showcase
  git switch demo/credential-free-showcase
  git push -u origin demo/credential-free-showcase

Create the PR:
  gh pr create --repo namansh70747/sentinel --base main --head demo/credential-free-showcase --title "Add simulated Sentinel investigation prototype" --body-file "/FULL/PATH/sentinel-handoff/transfer/PR-DESCRIPTION.md"

Once CI and required reviews pass, merge through GitHub or run:
  gh pr merge --repo namansh70747/sentinel --squash

Do not force-push or overwrite main. If the target branch already exists,
inspect it before importing/pushing. The bundle requires the existing upstream
base commit, which the full clone supplies.
